Understanding Snort alert precision and evasion

True Positives (Malicious): Exploits (e.g. Log4j CVE-2021-44228), Cobalt Strike C2 beaconing, MySQL authentication bypass, and brute force attacks that pose actionable operational risk.

False Positives (Benign): Diagnostic ping sweeps, broad regex matches against binary font files (NOOP sled heuristics), and high-frequency cloud DNS queries that trigger generic Snort rules.
